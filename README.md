# My Luma scout

A daily scheduled task looks around GitHub, Reddit and the web for new LG webOS home screen,
launcher and screensaver ideas, and files a digest here. Report only: it never changes code
on other branches or makes releases.

- `digests/YYYY-MM-DD.md` – one per day with findings (quiet days get no file)
- `backlog.md` – running prioritized table of enhancements (1 highly recommended, 2 nice to have, 3 maybe, 4 no). Updated daily; nothing is removed until Stephen says so. The same table ends each digest.
- `seen.json` – everything already reported, so nothing is reported twice
