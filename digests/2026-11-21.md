# My Luma scout digest — 2026-11-21

Sources checked: upstream lg-luma (v3.11.1, v3.12.0), watched repos (couch-tv, mytvlauncher changed; others unchanged), GitHub search for webOS launchers/screensavers, webosbrew apps-repo, web/Reddit search (nothing new there).

## Worth borrowing

- **B68 — Next calendar event under the clock** ([CanvasFrame](https://github.com/JWille/CanvasFrame)). A calm home screen that shows your next calendar event under the date. A small, glanceable addition to the glass clock, but it needs a calendar link over the network, so P3 at most (principles 3, 5). Must cache and fail quietly.

## Merge from upstream?

- **B67 — Centred move arrows** ([#367](https://github.com/ecklf/lg-luma/pull/367), v3.11.1). Cosmetic fix: the arrows shown while moving an app sit centred in their badge. Tiny and self-contained in `view.rs` with a test (principles 3, 7). P2.
- **B65 — Weather icon styles** ([#363](https://github.com/ecklf/lg-luma/pull/363), v3.12.0). Four bundled offline icon sets (Kuankuan default, Breezy, Lucide, Kickstand), a Show icon toggle, a one-line widget style and per-widget city name. Offline, but it reshapes the weather settings My Luma also uses with the glass clock, so Medium risk and P3 (principles 3, 7). This partly supersedes B28 (Compact weather styles): Stephen may want to merge or re-score B28 against it.
- **B66 — Attributions page** ([#363](https://github.com/ecklf/lg-luma/pull/363)). Read-only licences page under System. Only needed if the new artwork (B65) is taken; Low risk, P3 (principle 3).

## Already have

- **Dim the launcher's own screens at night** ([Free My TV fork](https://github.com/rodrigoborgesdeoliveira/free-my-tv)). My Luma's ambient already dims at night with pixel shift (principle 8). The same project's sunset-following light/dark and HDMI shortcut are covered by day/night wallpapers and favourites/inputs.
- **Return to the launcher when an app closes** ([mytvlauncher 66dab14](https://github.com/ViieeS/mytvlauncher/commit/66dab14)). Luma's Home takeover should already catch LG Home opening after an app exits; worth a quick check on the TV, no row.
- **Media-server Continue Watching rows** ([Hajadlo/lg-tv-home](https://github.com/Hajadlo/lg-tv-home), Jellyfin/YouTube). Same idea as B08; link added to B08's description.
- **Bing picture of the day** ([couch-tv 8e99763](https://github.com/Seagey/couch-tv/commit/8e99763)). Same idea as B11; link added there.

## Not for us

- **B69 — Remote app buttons open chosen apps** ([mytvlauncher 1a260cc](https://github.com/ViieeS/mytvlauncher/commit/1a260cc)). Works by injecting a hook into LG's input daemon; a crash there takes the remote with it (principles 1, 3). P4.
- **B70 — Reopen Home when an app closes to an input** ([couch-tv dbae3ed](https://github.com/Seagey/couch-tv/commit/dbae3ed)). Luma would grab the screen from an HDMI source, the exact thing B02 prevents (principles 1, 4). P4.
- **B71 — Spotify and football score cards** ([couch-tv 06e66e6](https://github.com/Seagey/couch-tv/commit/06e66e6)). Online widgets that add complexity (principles 3, 5). P4.
- **Keep tiles instead of rebuilding** ([couch-tv 849ffc2](https://github.com/Seagey/couch-tv/commit/849ffc2)). A DOM fix for a web launcher; Luma's native renderer doesn't rebuild HTML. No row.
- **iptvOS** ([repo](https://github.com/Creazawolf/iptvOS)). tvOS-style home with a built-in IPTV player and server hub; off-mission (principle 3).
- **Native Tv** ([repo](https://github.com/ihtisham1211/native-tv)). Privacy/debloat dashboard and MQTT bridge; not a launcher feature, and touches system services (principle 9).
- **jagosar/webos-launcher** ([repo](https://github.com/jagosar/webos-launcher)). Non-root webOS 4 launcher, untested on a TV; nothing new.
- **WEBOS-FW-BLOCK** ([repo](https://github.com/ohmybahgosh/WEBOS-FW-BLOCK)). Blocks LG firmware updates to keep root; outside Luma and a system change (principle 9). Possibly of personal interest, not a backlog item.
