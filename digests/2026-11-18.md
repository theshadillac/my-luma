# My Luma scout: 2026-11-18

Upstream went from v3.4.0 to v3.6.2 overnight. The 3.5.0 items already covered on 2026-11-17 (#287, #288, #292, #293) aren't repeated here. Twelve new home screen repos turned up as well.

## Merge from upstream?

- **Retry Home lifecycle after an update (v3.6.2, 9664872)**: https://github.com/ecklf/lg-luma/commit/9664872. Upstream now clears the "no lifecycle" fallback marker when the Luma version changes, and also clears an old empty marker. That way one failed focus check no longer forces slow full restarts on every Home press after updates. My Luma has the same `HOME_LIFECYCLE_OFF` marker (`/var/lib/luma-home/no-lifecycle`) and installs updates itself, so this looks like a direct fit. It touches `main.rs`, `platform.rs` and the tests (about 250 lines).
- **Keep Home preload launches hidden (v3.6.1, a137e43)**: https://github.com/ecklf/lg-luma/commit/a137e43. A preload launch of the Home replacement no longer steals the screen from a running app or HDMI input, while ordinary Home presses still raise Luma. If the G5 ever jumps to Luma while something else is playing, this is the fix. Worth checking whether My Luma's launch path has the same gap.
- **Lazy hidden pages (v3.6.0 patch, f87b78c)**: https://github.com/ecklf/lg-luma/commit/f87b78c. Apps and Settings now render only when needed instead of after every inventory refresh, and returning Home skips the old drawer's closing animation. It's a performance fix for Home relaunch and input lag, and it could go with the idle and animation ideas from yesterday's digest.
- **Favourites kept inside their glass card (v3.5.1, 2ac0eda)**: https://github.com/ecklf/lg-luma/commit/2ac0eda. The cut-off neighbouring tile is hidden and stops taking clicks or wheel input, and the drawer peek shows that more apps follow. This is a small visual fix. Check whether My Luma's favourites row shows the same clipping.
- **App drawer style setting (v3.5.0, c8935b5)**: https://github.com/ecklf/lg-luma/commit/c8935b5. The setting offers the default tvOS drawer with a peek of the app row, or a "Minimal" style with a lower dock and no peek. My Luma's tab-less Home with Down for the drawer differs, so it would probably need adapting rather than a direct merge.
- **Multiple widgets, market symbol edits, open Luma at power-on on webOS 5/6 (e041e17, 706b19b, 0526c11)**: these depend on upstream's widget grid, which we decided not to merge, or they only apply to webOS 5/6 and not to the G5 on webOS 26. Skip them.

## Worth borrowing

- **Online daily wallpaper sources with credits (Lumen, now Halcyon)**: https://github.com/ipatek420/Lumen-Launcher and https://github.com/ipatek420/halcyon. Wallpapers can come from Wikimedia featured pictures, Bing photo of the day, NASA APOD or a subreddit, with credits, rotation and slow drift, and a Green key skips to the next photo. My Luma's wallpaper cycle only uses uploaded images. An optional "photo of the day" source would add variety to Home and ambient mode without phone uploads.
- **Halcyon's "living sky" and Up for the wallpaper**: https://github.com/ipatek420/halcyon. A generated sky backdrop follows real sunrise and sunset through dawn, day, golden hour, dusk and night. Pressing Up slides the shelf away so only the backdrop shows. This pairs with yesterday's couch-tv four-period idea, and My Luma already knows the location from weather. A "just the wallpaper" peek is a small, cheap feature too.
- **Painting gallery with title caption (Glasshouse Dock)**: https://github.com/SikeXML/glasshouse-dock. It ships 27 public-domain paintings that rotate every 10, 30 or 60 minutes, with an optional title and painter in a corner. A bundled public-domain art pack plus an optional caption would suit OLED ambient mode. Credits are kept in a CREDITS file.
- **App Store icons for apps (ATLauncher)**: https://github.com/ratelimits/atlauncher. This QML Home for rooted webOS 25 fetches each app's Apple TV icon from the App Store and falls back to the webOS icon. It could be an optional "HD icons" source in My Luma's app artwork, but it means network lookups and fetching third-party artwork.

## Already have

- **myTV**: https://github.com/ViieeS/mytvlauncher. A native C/SDL2/LVGL tvOS-style home with paintings, a StandBy clock, a screensaver and glass that is blurred once and reused, so it uses almost no CPU when idle. My Luma covers the same ground. Its Control Center (picture modes, backlight, sleep) is LG system control and is ruled out.
- **ATLauncher hold-OK app menu**: https://github.com/ratelimits/atlauncher. Quit App, Edit and Delete on a long press. My Luma already has quit and delete in its app options.

## Not for us

- **APL Launcher**: https://github.com/Knikt/APL-Launcher. A web-based, multi-platform Apple TV clone with a Top Shelf, folders, profiles, debloat and a control center for picture settings. It runs on a web runtime and leans on system controls. Folders are the one idea worth remembering.
- **VICE Home**: https://github.com/ShaneRunham/VICE-Home. A personal home with on-screen alert cards over any app, a phone remote, Moonlight rows and homelab health. It's very bespoke. Overlay cards over other apps would need a separate overlay app.
- **FreeTV, TV Início, webos-vibehack (Sensation VN)**: https://github.com/PharmaJava/FreeTV, https://github.com/gustavo-koerich/tv-inicio, https://github.com/Sensationy2k/WebOS-Sensation-VN. Web apps for TVs that aren't rooted, using dev mode or tricks to return to Home. They do nothing a rooted native Luma lacks.
- **WMP-style visualizer**: https://github.com/championsnet/wmp-visualizer. Music visualizers with TV builds. It's a fun ambient idea, but it needs audio capture that Luma doesn't have.
- **couch-tv updates (to 4f1df37)**: https://github.com/Seagey/couch-tv. "Keep watching" now follows the app you're on, plus moving what's playing to another TV, a keyboard button for the phone remote and a privacy list entry. These depend on its bridge server or need several TVs.
- **Aerial clock-only decoder retry (#100, f6447e9)**: https://github.com/aabytt/custom-screensaver-aerial/pull/100. A fix inside the Aerial screensaver with no code for Luma.
- **webosbrew catalogue**: the only changes were Home Chooser 0.2.0 being listed under Launchers (already reported) and media apps (Kick TV, IPTV Player). Nothing relevant to the home screen.
