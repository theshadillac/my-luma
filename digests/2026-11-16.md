# My Luma scout: 2026-11-16

First full run. Upstream lg-luma 3.x (3.0.0 to 3.4.0) reviewed once. Watched repos unchanged (couch-tv, tvOS-Launcher, custom-screensaver-aerial).

## Merge from upstream?

Source: https://github.com/ecklf/lg-luma/releases (CHANGELOG at v3.4.0, 2026-11-15)

- **UI feedback sounds (3.2.0)**: optional tvOS-style navigate/select/Back sounds, synthesized in-house, off by default, silent fallback if audio fails. My Luma has no sounds. Fits as an opt-in General toggle; no LG system calls.
- **Usage-based app sorting (3.1.0)**: A–Z or "most used" order for the drawer, using local launch counts and leaving favourite order alone. My Luma's drawer has category filters and search but no usage sort. Good fit, low risk.
- **Weather widget styles (3.1.0)**: Standard, No icon and Compact styles with previews in Settings. Could sit next to My Luma's forecast and glass clock options.
- **Precomputed glass backdrops (3.2.0)**: blurred wallpaper backdrops are made during asset prep and upload instead of on first frame. This speeds up start. Worth checking against My Luma's wallpaper upload path if start-up or wallpaper changes feel slow.
- **Input badge fixes (3.2.1)**: amber badge when a connected input reports no signal, and hover badges that no longer get stuck. Small polish, fits the inputs menu.
- **Steam input icon (3.4.0) and Hungarian (3.4.0)**: easy cherry-picks. Steam icon only matters if a Steam device is on an input.
- **Hold Back for Recent apps (3.3.0)**: upstream now opens Recents only on a long press, everywhere. My Luma has `back_recents` (short Back on Home). This is a behaviour change, so take it only as an option, not a replacement.
- **Home widget grid (3.3.0)**: a 6×4 grid where greeting and weather can be moved, configured, removed and reset. This is a large redesign that would clash with My Luma's clock position, glass clock and ambient layout. Look at it for ideas, but do not merge it wholesale.
- **3.0.0 Liquid Glass redesign**: My Luma already has the tab-less Home, Down-to-drawer and corner quick panel that this release brought in. Upstream also removed app captions, greeting and date. Do not merge those removals.

## Worth borrowing

- **Arc Launcher (Android/Google TV)**: https://www.pulse.bot/consumer-tech/news/this-free-launcher-made-my-smart-tv-feel-like-it-should-have-all-along-3972b140-a2d0-44ff-a0e6-2e91a8ee3771/ (MakeUseOf, May 2026). An ad-free launcher whose one new idea for us is **local video wallpapers** alongside day/night wallpapers. A short looping video as a Home or ambient background could fit My Luma's wallpaper system, but performance on the G5 would need testing first.

## Already have

- **webosbrew Custom Screensaver**: https://repo.webosbrew.org/apps/org.webosbrew.custom-screensaver/ (repo last changed 2022). A root tool that replaces the stock screensaver. My Luma's ambient mode already covers this on Home.
- **Arc Launcher's rotating-clock screensaver and status bar**: My Luma already has an ambient glass clock with pixel shift, and shows the date and weather.

## Not for us

- **AltHome**: https://github.com/kitsuned/AltHome. A replacement stock home app for webOS 6+. Last commit was March 2026, it is a different codebase, and it offers nothing My Luma lacks.
- **webOS 10 homescreen customization**: https://github.com/mareklarek/webos10-homescreen-customization. Bind-mount overlay that reskins LG's own Flutter Home (May 2026). It changes the stock home, not a launcher.
- **R2D2 for webOS**: https://github.com/anubhavmalhotra/r2d2-tv (Show HN, Oct 2026). Streams a Linux host's home screen, browser and voice assistant to a rooted TV. A different architecture that needs one exact firmware build.
- **Idlegif**: https://repo.webosbrew.org/apps/org.oted.idlegif/. A GIF screensaver for the stock idle screen. My Luma's ambient mode makes it redundant.
- **Reddit r/webos this week**: one post shows a root bind-mount trick to swap the stock screensaver photos (LG Nano). It changes the stock screensaver, so it does not apply. No launcher posts.
