# My Luma scout: 2026-11-17

Upstream lg-luma has four unreleased commits on main after v3.4.0 (no new tag). couch-tv and custom-screensaver-aerial moved; tvOS-Launcher, AltHome, glass-tv and the others are unchanged. Several new webOS home-screen repos showed up on GitHub this week.

## Merge from upstream?

Source: https://github.com/ecklf/lg-luma/commits/main (after v3.4.0, all 2026-11-17, not yet released)

- **Smaller release binary (#293, a3e4234)**: full LTO, one codegen unit, and trimmed `owned_ttf_parser` features while keeping variable fonts. It's a 3-file build change with no behaviour change, so it's a cheap cherry-pick for a smaller IPK and faster in-app updates.
- **Configurable Recent apps Back behaviour (#287, 0eadcab)**: a setting for what Back does about Recents, with tests, and it partly undoes 3.3.0's long-press-only rule. My Luma has a `back_recents` toggle. Worth comparing, because upstream's version may be a superset that keeps both behaviours. If so, it fits "never lose functionality" better than the 3.3.0 change.
- **1x1 weather widget and in-popup weather size (#288, 0f7d2e3)**: depends on upstream's widget grid (3.3.0), which we decided not to merge. Only the small "compact weather" look is worth copying. The same PR fixes the nighttime greeting (#289), which may matter because My Luma keeps the greeting.
- **Crypto and stock price widgets (#292, 82e72bb)**: tied to the widget grid, and it adds network calls. Probably not for us unless Stephen wants tickers.

## Worth borrowing

- **couch-tv: own scenes follow the time of day**: https://github.com/Seagey/couch-tv/commit/0c04918. A user wallpaper can be tagged dawn, day, dusk or night, and tagged wallpapers rotate with the built-in pick for that time on a set interval. Optional 4K (@2x) copies fall back to 1080p. This would extend My Luma's day/night wallpapers to four periods with rotation inside each one. The 4K-with-fallback idea also fits the G5 panel.
- **couch-tv: let animations settle and rest while covered**: https://github.com/Seagey/couch-tv/commit/4e5d96d and https://github.com/Seagey/couch-tv/commit/d322c5e. Focus sway and glint stop after 6 s of no input. The home also pauses its timers and polling while an app or the screensaver is in front, and resumes them as soon as the home returns. My Luma has damage tracking, so it's worth checking that tile-lift animations and the clock or weather timers really idle when nothing changes or Luma isn't visible. It could save GPU time and wear on the OLED.
- **Ambient instead of "No Signal"**: https://github.com/FrAcTi0N/webos-aerial-nosignal. A root watcher reads the read-only `videooutput/getStatus` signal state and shows a screensaver when an HDMI source has had no signal for about 30 s. Any key brings the input back. As a My Luma idea, an input with no signal could fall back to Luma's ambient or glass clock. The watcher's power-off and Kodi-wake parts are system controls, so leave those out.
- **Plex rows on the home**: https://github.com/Commanderx-code/webos-launcher. A minimal webOS launcher with Continue Watching, Watchlist and Recently Added rows from a Plex server, plus "Recently Used" across apps and inputs. Stephen runs Plex, so a single optional Continue Watching row or ambient artwork source could fit. It needs a Plex token kept in settings, never in logs. The same repo's "Ambient" theme, where the focused app's colour glows behind the grid, is a small visual idea too.

## Already have

- **Homebar**: https://github.com/rawinek/webos-homebar. A rooted launcher with per-input names and icons (61 device icons), favourites set on the TV, usage-sorted apps and a settings live preview. My Luma already has input renaming and icons, favourites and (via upstream 3.1) usage sort. Its main idea, a bar over the playing picture instead of a full-screen home, is a different product.
- **LGlow Atlas**: https://github.com/maskodroids-code/LGlow-Atlas. A fork of LGlow with weather for a chosen city and a framed-art slideshow screensaver with an interval picker. My Luma's weather location, wallpaper cycle and ambient mode cover this.

## Not for us

- **Aerial screensaver webOS 26 startup hardening**: https://github.com/aabytt/custom-screensaver-aerial/pull/92. It fixes video, decoder and notification startup on webOS 26 and reports "launch accepted" separately from "playing". This only matters if Stephen uses Aerial as the system screensaver on the G5. It has no code for Luma.
- **Home Chooser**: https://github.com/webosbrew/home-chooser. An official webosbrew app that sets which installed launcher the Home button opens, keeps the choice after a restart, and restores LG Home if the launcher is removed. My Luma already has its own Home setup. Still, it's a handy recovery tool to know about.
- **Glasshouse**: https://github.com/rorygallagher2024/glasshouse. An on-TV dashboard with privacy controls, OLED care, a Home Assistant MQTT bridge and debloating. It's mostly LG system control, which is ruled out for Luma.
- **quiet-skies**: https://github.com/marelucent/quiet-skies. QML screensavers for Glasshouse: a starling murmuration and a planned real-time "window sky" from your latitude and longitude. They're tied to Glasshouse's format and cost about 25% of a core. The live-sky idea is a fun ambient concept for later.
- **Clean Your TV**: https://github.com/Razdva122/clean-your-tv-lg-webos. A web-app home with Classic, Liquid Glass and Ribbon themes and community themes. Its themes are built for a web runtime and My Luma's native renderer can't use them.
- **WiiOS**: https://github.com/KaykCaputo/WiiOS-webOS. A Wii-style launcher with channels and music. It's a novelty theme with nothing that fits My Luma.
