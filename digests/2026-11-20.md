# Scout digest 2026-11-20

## Worth borrowing

- **Plex "Continue Watching" / recently added shelf (DrentOS, LG build)** — https://github.com/ramondrent/drent-os
  A CleanFrame-based personal launcher whose LG version adds a scrolling Plex Continue Watching and recent-additions row with direct handoff into the native Plex app. Fits well since Plex already runs on the iMac: a read-only row on Home, fed by the Plex server API, without touching LG system controls. My Luma only knows Plex as an app icon today.

- **"Loop look": photo turned into a seamless slow-zoom loop with a depth cut-out over the clock (couch-tv)** — https://github.com/Seagey/couch-tv (commits 87ecb4c..a8a3eda, `make-loop.sh`)
  A helper script turns one photo into a seamless push-in/out clip at four times of day, plus a depth matte so the clock sits behind the subject (iPhone lock-screen style). For My Luma, the cheap version is a precomputed matte PNG drawn above the glass clock on day/night wallpapers in ambient mode; the video loop is optional and heavier.

- **One-file problem report (glasshouse-dock)** — https://github.com/SikeXML/glasshouse-dock (commit 27afea7)
  Writes a single file with TV model, firmware, app versions and what went wrong. A "Copy diagnostics" item in My Luma's settings would help when the in-app updater or Home takeover misbehaves; must leave out any tokens/webhook URLs.

- **Settings backup and restore (PureTV)** — https://github.com/Heymez0/PureTV
  Android-first launcher with backup/restore of the whole layout and settings. My Luma has no export; a JSON backup of Preferences (favourites, input names, webhook tiles minus secrets, ambient options) would protect against losing setup on reinstall.

- **Deep-link video cards (couch-tv)** — https://github.com/Seagey/couch-tv (PR #288)
  Tiles that open a specific YouTube video rather than just the app. Could extend My Luma's shortcut tiles with an app+launch-params target. Lower priority.

## Merge from upstream?

- **lg-luma v3.10.1 and v3.11.0** — https://github.com/ecklf/lg-luma/releases
  v3.10.1: restores glass focus ring and applies text tint in the fragment shader (fix for a visual regression). v3.11.0: wrap-around navigation in favourites and the app drawer (#357), and render perf work (vertex array objects, grouped card logo draws, compact one-channel shadow masks; ~2 ms less CPU per drawer frame on a Mali TV, #333). The perf and focus fix look like safe wins; wrap navigation is behaviour Stephen should try before adopting (it changes how Down/edge presses feel on the tab-less Home).

## Already have

- **Dusk TV** — https://github.com/mkrosz/dusk-tv — clean home with rotating photos, real app logos, clock, Wi-Fi and weather; My Luma covers all of it.
- **couch-tv optional Inputs tile / grid scrolls with focus** — https://github.com/Seagey/couch-tv (PRs #294, #296) — My Luma already lists and renames inputs and scrolls its drawer.

## Not for us

- **couch-tv gear menu with Wi-Fi, Bluetooth, Screen off** (PR #286) — system controls, ruled out.
- **Modern LG Hub** — https://github.com/paulhoehne2006-a11y/Modern-LG-Hub — screen-off mode, local smart-home tiles and a Gemini assistant; screen off is a system control and webhook tiles already cover smart home.
- **OmarchyTV** — https://github.com/piermark/omarchytv — Omarchy-themed multi-platform launcher with a live-sky screensaver and phone-gamepad arcade; heavy theme, webOS build only "testing".
- **LG Home Helper** — https://github.com/TheoGal/lg-homehelper — no-root Home/app-button remapper; My Luma already takes over Home on the rooted TV.
- **LG TV Control** — https://github.com/kayloehmann/lg-tv-control — NAS dashboard that changes TV settings over SSH; system settings, out of scope.
- **awesome-webos** — https://github.com/tolgakurtuluss/awesome-webos — curated list; useful as a scouting source, nothing to build.
